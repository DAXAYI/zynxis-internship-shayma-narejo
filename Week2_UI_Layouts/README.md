# Week 2 - Layouts & Styling
# Zynxis Mobile UI

A Flutter mobile UI project created to recreate the **Zynxis landing page** using a professional charcoal/slate-grey dark theme.

## Task: Layouts & Styling

The objective of this task was to practice Flutter layout and styling concepts by building three responsive mobile UI screens.

### Screens Created

1. **Home**

   * Zynxis hero section
   * Company introduction
   * Explore Services button
   * Contact Us button
   * Web, Mobile, and AI categories
   * Decorative layered background elements

2. **About**

   * Company introduction
   * Mission section
   * Modern, Scalable, Secure, and AI-Driven feature cards

3. **Services**

   * Web Development
   * Mobile Development
   * AI Solutions
   * Custom Software

## Flutter Concepts Practiced

The project demonstrates the use of:

* `Row` — horizontal layouts and content groups
* `Column` — vertical page layouts
* `Stack` — layered and overlapping UI elements
* `Container` — cards, backgrounds, borders, and styled sections
* `Expanded` — responsive distribution of available space
* `SingleChildScrollView` — scrollable mobile layouts
* `NavigationBar` — navigation between the three screens
* `Positioned` — placement of decorative elements inside a Stack

## Project Structure

```text
lib/
├── main.dart
├── home.dart
├── about.dart
└── services.dart
```

* `main.dart` — application setup, theme, and navigation
* `home.dart` — Home screen UI
* `about.dart` — About screen UI
* `services.dart` — Services screen UI

## Design

The application uses a professional dark interface based primarily on:

* Charcoal
* Slate grey
* Dark navy/slate backgrounds
* White headings
* Muted grey secondary text

The design was created specifically for a modern technology/software company interface.

## Running the Project

Make sure Flutter is installed and configured.

Install project dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```
